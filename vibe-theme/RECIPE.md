# Vibe a Television theme in about two minutes

## What a theme can do

- `theme.css` reaches the application and artifacts using a theme-capable live canonical version. It can change colors, fonts, surfaces, frames, wallpaper, and existing markup with narrow selectors. CSS can move, tilt, sway, or filter card frames and animate wallpaper layers; `card-sway.css` gently rotates the selected `.artifact-frame`. Decorative sidebar surfaces can move too, but transforming the whole sidebar risks its collapse, resize, focus, and pointer behavior. Keep the app-owned `.page` transforms, sidebar sizing, clipping, selection, and pointer behavior intact. Frozen canonical v1 and third-party pages keep their own styling.
- `iframe-background.js` paints in a transparent sandbox **behind** the app; an opaque wallpaper can hide it. `iframe-overlay.js` paints **above** the app and all card frames. Each reaches only its own frame document, not the app or artifact DOM. Television passes limited pointer messages; neither frame receives direct input. Both run without main-page consent and are recreated on theme or appearance refresh. Each needs its matching `enableIframeBackgroundJS` or `enableIframeOverlayJS` manifest flag. Never set their document `color-scheme`.
- `main.js` reaches the main app DOM, browser globals, storage, and network APIs, but never artifact documents. It needs `enableMainJS: true` and runs only after the user grants consent for the exact theme ID in Settings; selecting a theme does not grant consent. Internal app nodes are not a stable script API. For a fast reveal, use CSS and sandboxed frames instead. Main scripts also need repeat-safe cleanup when the active package refreshes.
- Assets live inside the theme folder. Bundle fonts with their license, load them through `@font-face` using a path relative to `theme.css`, and reserve display fonts for short labels; keep `--font-sans` readable for body copy. Local SVGs and CSS gradients need no network. The contract defines no theme sound API. A consented `main.js` can attempt ordinary browser audio, but [autoplay may be blocked](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay); the sandboxed frames have no direct user gesture. This stage recipe uses no sound.

## Build from one sentence

Every generated theme gets **all five**: a sky-and-silhouette wallpaper scene; at least **three moving parts** (two prompt-specific sprites plus weather is the quick default); **two or three small inline SVG drawings** made for the prompt as sprites and edge props, reused where useful; a loud display font with readable body text; and a coordinated, high-contrast palette. A recolor alone is unfinished.

1. `cd /root/workspace/dev/tv-demos/vibe-theme`. Run `tv focus-status`; remember `activeThemeName` for the return switch (`null` means `tv set-theme None`). Choose a fresh ID and set `dest=/root/.television/themes/your-fresh-id` (replace `your-fresh-id`). Confirm it does not exist, including as a broken symlink, with `test ! -e "$dest" && test ! -L "$dest"`; then `cp -R template "$dest"`. Never replace an existing theme folder.
2. Build the scene: redraw `$dest/assets/silhouette.svg` for the prompt (forest, skyline, sea floor, dunes). Run `cat effects/wallpaper-scene.css >> "$dest/theme.css"`; edit the four `--scene-*` paints in the new file. The `--app-wallpaper-image` URL resolves against `theme.css`. A moon or sun is included; set `--scene-orb: transparent` to hide it.
3. Run `cat effects/sprites.js effects/weather.js effects/edge-props.js > "$dest/iframe-overlay.js"`. In that new file, draw two short inline SVGs for the sentence and set each sprite's `motion` (`drift`, `flap`, `rise`, `fall`, `orbit`, `bounce`), `edge`, and `sizePx`. Set weather `KIND`, `COLOR`, and `COUNT`: `rain`, `snow`, `embers`, `bubbles`, or `confetti`. Replace the sample webs in `PROPS` with a prompt-specific corner or edge drawing (cobweb, vine, icicle, neon tube, bunting), or reuse one sprite SVG. Give SVG gradients and filters unique IDs when reusing markup in the same frame. Two sprite motions plus weather meet the three-moving-parts rule. Add `"enableIframeOverlayJS": true` to the manifest.
4. Pick a display face: **Creepster** (`fonts/creepster`, horror), **Monoton** (`fonts/monoton`, neon), or **Bungee Shade** (`fonts/bungee-shade`, comic/carnival). Copy its sole `effects/fonts/<choice>/*.ttf` to `$dest/assets/display.ttf` and its `OFL.txt` to `$dest/assets/display-OFL.txt`. Run `cat effects/display-font.css >> "$dest/theme.css"`. It styles headings and shell titles; leave `--font-sans` as a readable body stack. These bundled fonts are from [Google Fonts](https://github.com/google/fonts).
5. Make the base palette fit the sentence: edit the four semantic colors together (`--color-surface`, `--color-surface-muted`, `--color-text`, `--color-text-muted`), then `--accent`, border, sidebar, selected channel/tab, frame, and titlebar values in `theme.css`. Keep ordinary text at least 4.5:1 against both surfaces. Give wallpaper controls an opaque enough `--wallpaper-overlay-background` and matching text color. Pick `colorScheme: "dark"` or `"light"` for the fixed look; do not set CSS `color-scheme`.
6. For more chaos, append **one** of `effects/screen-crt.css` or `effects/screen-glitch.css` to `$dest/theme.css`; optionally append `effects/card-sway.css`. Screen snippets use the permanent foreground overlay. Card sway animates `rotate` on the selected frame, leaving the stage transform alone. Keep effects legible and honor reduced motion. Write a two-line README: a title, then the visual intent, asset source, script effects, and their small cost. Set the manifest name and keep `authoredForAppVersion: "1.5.0"` for this demo. Run `tv set-theme <id>`; return with `tv set-theme <previous-id>` (or `None`).

### Worked example: “underwater disco”

| File | Exact choice |
| --- | --- |
| `manifest.json` | `name: "Underwater Disco"`, `colorScheme: "dark"`, `enableIframeOverlayJS: true` |
| `theme.css` | Template plus `wallpaper-scene.css`, `display-font.css`, `card-sway.css`; surfaces `#071525` / `#112c3b`, text `#e7fcff` / `#b2d9e0`, accent `#ff68c6` |
| `assets/silhouette.svg` | Draw a dark sea-floor ridge with coral and two speaker-shaped towers; no external image |
| `wallpaper-scene.css` constants | `--scene-sky-top: #06112b`, `--scene-sky-bottom: #174e70`, `--scene-orb: #f8b5ff`, `--scene-haze: rgb(255 75 220 / 26%)` |
| `assets/display.ttf`, `assets/display-OFL.txt` | Copy `effects/fonts/monoton/Monoton-Regular.ttf` and its `OFL.txt` |
| `iframe-overlay.js` | Concatenate `sprites.js`, `weather.js`, `edge-props.js`; draw a jellyfish SVG with `motion: "rise", edge: "left", sizePx: 58`, and a disco-ball SVG with `motion: "orbit", edge: "right", sizePx: 64`; reuse the disco-ball SVG as a `top-right` edge prop at `sizePx: 94` |
| `weather.js` constants | `KIND = "bubbles"`, `COLOR = "#73f5e9"`, `COUNT = 18` |

The two inline SVGs plus the sea-floor SVG are the three new drawings. The jellyfish rises, the disco ball orbits, bubbles rise, and the selected card sways. For a fast fallback, `./install.sh halloween`, `./install.sh haunted-kitchen`, or `./install.sh deep-sea` copies a prepared theme under a fresh demo ID and prints the switch command.
