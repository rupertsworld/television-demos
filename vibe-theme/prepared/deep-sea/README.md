# Bioluminescent Deep Sea

Intent: An abyssal observatory, with near-black blue glass, cyan organism light, hints of pink, and slow bubbles. Fixed dark appearance preserves the same night-ocean contrast under either saved appearance preference.

The four semantic colors style Television and live canonical artifacts. The app-only wallpaper adds large, dim radial glows; soft cyan rims and rounded frame corners make artifacts read as lit observation windows. Local sans-serif fonts avoid a network dependency. Cyan is the focus and action hue; pink remains a secondary decorative palette seed.

The sandboxed `iframe-overlay.js` draws eleven small translucent rings rising across the screen, including over artifact frames. It has no application DOM access or pointer input. CSS transform and opacity animations run per ring; reduced-motion hides them. No assets or main-page script.
