# Haunted 1970s Kitchen

Intent: A haunted 1970s kitchen with avocado appliances, harvest-gold recipe cards, dark wood cabinetry, and a sickly fluorescent ceiling. Fixed light appearance keeps the cream artifact documents readable while the shell stays dark and theatrical.

The four semantic colors tint Television and live canonical artifacts. The app-only wallpaper uses CSS gradients to suggest old linoleum and a dim lamp; the sidebar and thick artifact frame suggest stained wood and a recipe tin. Georgia and Bookman are local fonts, so the reveal does not depend on a network font.

The sandboxed `iframe-overlay.js` combines faint rising green glyphs with a stepped fluorescent flicker and scanlines. It paints over the app, including artifact frames, without DOM access or pointer input. Nine glyph animations and one stepped opacity animation run per screen; reduced-motion hides the glyphs and stops flicker. No assets or main-page script.
