# Demos

For Diff & Demo night, Wednesday October 14. Playful and weird; each one uses something only Television can do.

## Building

- **Fridge-magnet poetry.** Drag a word from the pile onto the fridge. The agent gets a message, picks a word of its own and drags it up next to yours, and together you write a poem. Simple version first, then full graphics.
- **Vibe a theme.** One sentence, such as "make Television look like a haunted 1970s kitchen", and the agent writes a new theme and switches to it: the whole app and every card change at once, with a living effect like flicker or drifting steam. Two prepared themes stand by in case live generation is slow.
- **Words from the room.** People scan a QR code and send one word; it lands on the fridge as a new magnet and the face reacts out loud. Only plain code and a model with no tools ever see what the room types.
- **The agent's face.** A card that gives the agent a face. The agent sends it something to say, spoken out loud, and a mood; the mouth moves as it talks. Output only.

## Ready

- **Television MCP prototype.** The running prototype, on the channel as a web page, for one weird thing in the next version of Television.

## Maybe

- **A pet the room looks after.** Gerald's body, hats and diary are all data. The room sends requests through the QR form ("give him a hat", "make him a jellyfish"); a sandboxed agent with no tools draws each change, Rupert approves it, and it appears. A moustache Rupert draws on him survives every new body, which proves it's the same pet.

## Ideas
- **Ouija board.** The agent spells answers to the room's questions by moving the planchette.
- **The agent plays, then cheats.** Noughts and crosses, until the agent changes the rules mid-game.
- **Exquisite corpse.** Head, body and legs drawn by you, the agent and the room, then revealed.
- **The room has the remote.** A read-write share link lets people change the screen from their phones. Riskiest.
